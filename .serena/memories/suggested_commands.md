# Commands (Darwin/npm)

- `npm run dev` — start local Next development server.
- `npm run build` — production build; generates ignored `.next/`.
- `npm start` — serve a completed production build.
- `npm run lint` — run ESLint.
- `npm run typecheck` — run `tsc --noEmit`; Next-generated types may require `npm run build` or `npm run dev` first after deleting `.next/`.
- `npm run db:generate` — generate Drizzle migrations.
- `npm run db:migrate` — apply Drizzle migrations using root env files.
- `rg --files` — preferred fast file listing/search utility on Darwin.
- `serena memories check` — check memory references and stale entries.
